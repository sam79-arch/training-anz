🔗 Mô Phỏng 3 Con Trỏ: Reverse Linked List

LeetCode #206 (Easy) • Sliding 3 Pointers (prev, curr, next) & In-place Reversal

Bước 1 / 1
Chọn kịch bản test:
Cấu trúc danh sách liên kết trên V8 Heap: 5 Nodes (Standard)
prev (Đã đảo ngược)
curr (Đang bẻ mũi tên)
next (Giữ node sau)
null: Đích trỏ ban đầu & kết thúc
THỰC THI 4 DÒNG LẶP CỐT LÕI: O(1) Memory
1: const next = curr.next; // Cất giữ node sau
2: curr.next = prev; // Bẻ ngược mũi tên
3: prev = curr; // Tiến prev
4: curr = next; // Tiến curr
GIẢI THÍCH CHI TIẾT: Khởi tạo

Khởi tạo 2 con trỏ ban đầu: prev = null, curr = head. Chuẩn bị bước vào vòng lặp duyệt tuyến tính.

In-place invariant: 0 node mới cấp phát
